# Build an Authored, Quiet System Instead of a Repeated Portfolio Template

## Decision

Create a coherent portfolio identity through restrained hierarchy, conversational voice, real evidence, composition, and meaningful motion—while allowing each project a composition suited to its story. Consistency comes from shared taste and system rules, not identical page templates.

## Context and viewer problem

Early versions were described as SaaS-like; later stylistic attempts competed with meaning. Repeated cards, large headings, arrows, handwriting, tilts, and staged mockups made the work feel generic. Family Finance also needed more materiality and causality than the approved About or Tiny Tool compositions.

## Previous state and alternatives

- Reuse one standard case-study template.
- Give every page an unrelated art direction.
- Use one quiet shared system with project-specific composition.

Generic UX templates, decorative arrows, handwriting, typewriter styling, tilted screens, huge type, endless cards, and applying Tiny Tool's centered structure to Family Finance were rejected.

## Resulting logic and trade-offs

Typography, grid, margins, rhythm, warmth, and quality standards remain shared. Family Finance can add evidence materiality and stronger narrative motion. This requires more page-specific design and QA but prevents template sameness.
