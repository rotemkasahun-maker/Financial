# Case Study Evidence Harvester

Capture:
- real problem
- context and constraints
- original behavior
- screenshots/messages/UI evidence
- failed attempts
- research/reference used
- alternatives considered
- decision and rationale
- implementation evidence
- before/after
- outcome
- remaining uncertainty
- lesson

Label claims as:
OBSERVED / USER_REPORTED / MEASURED / IMPLEMENTATION_FACT / INFERENCE / DESIGN_DECISION.

Do not convert inference into outcome.

Flag personal, financial, or medical identifiers for redaction before publication.

Do not derail active work; append a compact evidence packet.
