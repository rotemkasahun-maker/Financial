# FigJam Project Plan Adapter

Inspired by Figma's public generate-project-plan workflow.

## Research first
Ground in:
- PRD/user goal
- canonical repo/design source
- current architecture
- active constraints
- known blockers

## Candidate sections
Use only what is relevant:
Motivation, Scope, Non-goals, Current system, Proposed behavior, Architecture/data flow, Design decisions, Dependencies, Risks, Open questions, Milestones, QA/acceptance, Rollout/migration.

## Plan blocks
Choose the clearest shape: concise text, table, decision columns, sticky list, diagram, or timeline.

## Do not
- create decorative boards without actionable content
- invent dates/owners
- duplicate the PRD verbatim
- plan before checking canonical context

## Output
Objective
Current state
Scope
Non-goals
Dependencies
Decision log
Work packages
Acceptance criteria
QA
Risks
Open questions
Handoff/ship criteria
