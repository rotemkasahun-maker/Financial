# Figma Video Interaction Review

Adapted to our workflow from Figma's public video-interaction-mapper pattern.

## Workflow
1. Validate video and duration.
2. Create a quick timeline scout/contact sheet when tooling allows.
3. Select meaningful state changes, usually 5–15.
4. For each transition capture: before, after, trigger, visible target, changed region, confidence.
5. Do not infer a trigger if evidence is insufficient.
6. Produce a storyboard plan for Figma or a motion implementation spec.
7. Verify final implementation against selected frames.

## QA
Check viewport/crop, state order, interaction target, entry/exit motion, easing/duration if inferable, clipping, text reflow, overlays, scroll position, responsive behavior.
